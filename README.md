# gotodo-operator

Charmhub package name: gotodo-operator
More information: https://charmhub.io/gotodo-operator

A Juju machine charm for GoTodo, a small todo app. It installs GoTodo from GitHub releases, runs it under systemd, and integrates with alloy-sub, profiling and Grafana.
